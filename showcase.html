Can I use this in a commercial project?

Yes. The system is designed to be copied, customized, and shipped in any project.

Does it require JavaScript?

No. Visual styles and native interactions work with HTML and CSS alone. Add small scripts only when your product behavior requires them.

How do I change the brand?

Override the semantic custom properties in :root. Components inherit the new theme automatically.
